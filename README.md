# 🤖 Sistema de Ranking RoboCup

## 📖 Sobre o Projeto

Este projeto foi desenvolvido em Java para a disciplina de Laboratório de Programação na FIAP durante a Sprint 3.

O sistema simula o processo de ranking das equipes da RoboCup, coletando dados, resultados dos combates e notas de design dos robôs. Após processar todas as informações, o programa gera uma classificação final baseada nas regras da competição.

---

## ⚙️ Funcionalidades

- Cadastro das equipes participantes
- Validação de números únicos de equipes (de 10 a 99)
- Inserção da nota de design do robô
- Registro dos resultados dos combates
- Cálculo automático da pontuação
- Geração de ranking ordenado por pontos
- Sistema de desempate baseado na nota de design do robô

---

## 🛠 Tecnologias Usadas 

- Java
- IntelliJ IDEA
- Lógica de Programação
- Arrays e Loops
- Estrturas condicionais e matrizes

---

## 📊 Regras de Classificação

O ranking das equipes é calculado de acordo com as seguintes regras:

- Vitória = 7 pontos
- Empate = 4 pontos
- Derrota = 0 pontos

Em caso de empate na pontuação, a nota de design do robô é utilizada como critério de desempate.

---

## 💻 Como Funciona

O usuário informa a quantidade de equipes participantes.
Cada equipe recebe um número de identificação único.
A nota de design de cada robô é registrada.
Os resultados dos combates são registrados como: V = Vitória; E = Empate; D = Derrota
O sistema calcula a pontuação total.
O ranking final é exibido em ordem decrescente.
